Desarrollado con metodología Scrum

Este proyecto académico implementa las mejores prácticas de desarrollo ágil

🎯 Funcionalidades Core

Foros internos por materia, pizarras compartidas, subida de archivos y agendas grupales desarrolladas siguiendo el framework Scrum.

📋 Product Backlog

Historias de usuario definidas con criterios SMART y puntos de historia asignados mediante planning poker.

⚡ Sprints Iterativos

Entregas incrementales de valor cada sprint con Sprint Planning, Daily Scrums, Sprint Review y Retrospectivas.

🔄 Mejora Continua

Implementación de los 3 pilares de Scrum: transparencia, inspección y adaptación en todo el proceso de desarrollo.
